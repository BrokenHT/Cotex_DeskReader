# Legado 手机书架（可选功能）

Cotex 默认是纯本地阅读器：导入 TXT / EPUB，书库和进度全部存在本机 `%APPDATA%\DeskReader`，不连接任何设备。

**Legado 手机书架是可选项，默认关闭。** 打开后，Cotex 可以读取安卓手机「阅读」（Legado）里的书库和章节，并把阅读进度写回手机。

关闭时，Cotex 不会发起任何手机连接，行为与没有这个功能时完全一致。

## 开启方式

1. 打开 Cotex → 左下角「更多设置」→「Legado 手机书架」。
2. 打开「启用」开关。
3. 选择连接方式（USB / ADB 或 HTTP 直连），填写对应参数。
4. 点击「同步手机书架」。

## 两种连接方式

| | USB / ADB | HTTP 直连 |
| --- | --- | --- |
| 前提 | 手机开启「USB 调试」，首次插线时在手机上授权本机 | 手机与电脑同一局域网，Legado 的「Web 服务」已启动，并知道手机 IP 与端口 |
| 需要手机亮屏 | **不需要** | **需要**，锁屏或息屏后连接会中断 |
| 稳定性 | 插线即可用，长期稳定 | 受手机休眠、IP 变化、Web 服务被系统回收影响 |
| 适用场景 | 日常使用 | 不方便插线时临时使用 |

> **关于 HTTP 直连**：安卓会在一段时间无操作后让 Web 服务休眠。保持手机亮屏（可在开发者选项中开启「充电时不锁屏」）才能完整使用读取与进度回写。若同步中途失败，先点亮屏幕再重试。

> **关于 USB 直连**：只需要在手机上开启「USB 调试」并授权本机一次，之后插线即可，**不需要手机亮屏**。

## 参数说明

- **ADB 路径**：留空时自动查找 PATH、Android SDK 以及 `C:\platform-tools\adb.exe`。
- **设备序列号**：连接了多台设备时用于指定其中一台；只有一台设备时留空即可。
- **手机 Web 服务地址**：仅 HTTP 模式使用，形如 `http://192.168.1.20:1122`。

## 工作方式

- **读取**：书架与目录从手机拉取；章节正文按需下载并缓存在本机，重新打开不需要再联网。
- **进度**：以本机为准。每次阅读位置变化先写入本地，再尝试写回手机；写回失败只提示「待重试」，不影响继续阅读。
- **坐标换算**：Cotex 用「章节 + 段落」，Legado 用「章节 + 章内字符偏移」。写回时会按已缓存的正文换算成字符偏移，因此首次写回某章时可能需要先下载该章正文。
- **隐私**：书名在侧边栏使用工作标题显示，鼠标悬停才显示真实书名；所有数据保存在本机，不上传任何服务器。

## 关闭功能

把「启用」开关关掉即可。已同步的书仍保留在本机，可继续离线阅读，只是不再与手机通信。

## 常见问题

**进度没有写回手机？**
检查开关是否打开、手机是否连接。若提示「已保存到本地，手机进度待重试」，说明本机已保存，联网或点亮屏幕后会自动重试。

**找不到 ADB？**
安装 Android Platform Tools，或把 `adb.exe` 的完整路径填进「ADB 路径」。
